# Guía de Usuario – BioTech v1.0.0

Bienvenido a BioTech, la plataforma premium para el control inteligente de materiales y maquinaria industrial.

## 1. Acceso al Sistema
1. **Inicio de Sesión:** Ingrese su número de teléfono y contraseña autorizados.
2. **Biometría:** Si su dispositivo lo soporta, puede habilitar el acceso mediante huella digital o reconocimiento facial para mayor rapidez.
3. **Estado del Servidor:** En la parte inferior verá un indicador (Verde/Naranja) que informa si está conectado al servidor central.

## 2. Panel de Control (Dashboard)
Desde aquí puede visualizar los indicadores clave (KPIs) de su operación:
- Máquinas registradas y activas.
- Porcentaje de avance global.
- Acceso rápido a las secciones principales mediante la barra de navegación inferior.

## 3. Gestión de Inventario y Maquinaria
- **Lista de Máquinas:** Visualice el estado técnico de cada unidad. Los colores indican si la máquina está operativa (🟢) o requiere atención (🔴).
- **Materiales:** Controle el stock en tiempo real. La aplicación le alertará cuando un material alcance niveles críticos.

## 4. Trabajo Sin Conexión (Offline)
BioTech está diseñado para trabajar en entornos industriales con baja conectividad:
- Puede crear registros o actualizar información incluso si no hay señal.
- Los cambios se guardarán automáticamente en su dispositivo.
- Una vez que recupere la conexión, la aplicación sincronizará todo el trabajo pendiente con el servidor.

## 5. Reportes y Auditoría
- **Generación de Reportes:** Seleccione el tipo de reporte deseado y elija el formato (PDF o CSV).
- **Timeline de Auditoría:** Revise el historial cronológico de todas las acciones realizadas en el sistema para una trazabilidad total.
